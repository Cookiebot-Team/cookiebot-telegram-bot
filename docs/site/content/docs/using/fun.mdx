The half of the bot nobody strictly needs and every group turns on anyway. All
of it is switched out at once with **Fun Functions** in
[`/config`](/docs/using/configure) — with two exceptions noted below, because
the switch a command obeys is v1's, not a tidier one invented here.

<Callout>
A command in a switched-off family **says so**. It does not go quiet: "fun
functions are disabled for this group" is a much better answer than silence
when someone is wondering whether the bot is broken.
</Callout>

## Talking to the bot

Mention the bot, or reply to something it said, and it answers in character —
no command needed. A voice note replying to the bot works the same way: it is
transcribed, answered, and the transcript itself is never posted. See
[AI features](/docs/using/ai) for what that costs and how it is configured.

Two limits worth knowing:

- **Seven in a row is the cap.** One person mentioning the bot over and over
  gets six answers and then silence. Sending ordinary messages replenishes it —
  the bot stops being a toy for one member without ever refusing out loud.
- **A closed Fun switch is silent here**, not a refusal. A conversational reply
  that answers "fun functions are disabled" reads as the bot talking back about
  not talking back.

Replying to the bot **with a sticker** gets a sticker back, drawn from the pool
it has collected. Only stickers seen in safe-for-work groups go into that pool.

## Commands a group invents for itself

A deployment can attach a picture pool to a name — `/louie`, say — and that name
becomes a command in the groups that brand serves. Plain `/louie` posts one at
random, captioned with the pool's name and the picture's id; `/louie 1` asks for
that exact one. A number nothing matches, or a name with no pool behind it,
gets no reply at all.

Custom commands follow the **Fun Functions** switch, and only exist for brands
whose command set includes them.

## Convention posters

`/bff`, `/patas`, `/fursmeet`, `/furcamp`, `/pawstral` and `/trex` post a
picture of the event with a countdown to it. They are covered on
[Giveaways and events](/docs/using/giveaways#convention-posters) — and they
ignore both the Fun and Utility switches, in every group.
