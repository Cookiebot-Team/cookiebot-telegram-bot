title: Moderation
description: What the bot does on its own — the captcha, sticker floods, the media hold, blocked accounts
---

Most of Cookiebot's value is in what happens while nobody is watching. Four
things run unprompted, and all four need the bot to be an admin with **delete**
and **ban** rights.

## Screening joiners

A new member gets a challenge in the group and has **🕒 CAPTCHA** seconds to
answer it — by replying with the answer, or by tapping the button. An admin can
wave someone through with the approve button.

Fail it, or let the timer run out, and the member is removed. **Removal is not a
permanent ban**: the block is lifted shortly afterwards so a real person who put
their phone down can come back and try again. That matters, because the most
common captcha failure is exactly that.

Set **🕒 CAPTCHA** to `0` to turn screening off entirely.

## Sticker floods

Stickers are the cheapest way to make a group unreadable — a client can send
them faster than anyone can scroll. The bot counts stickers per member within a
rolling window:

- at exactly **Stickers limit** (default 5) it **warns once**;
- past the limit it **deletes** every further sticker.

A conversation held in stickers between two people is counted per person, so it
is not treated as a flood. If the bot cannot reach its counter, it does nothing
rather than guessing — silence beats deleting a message that was fine.

## Holding back new members

**🕒 Limbo** stops a member who has just joined from posting images and files
for a set number of seconds. The bot says how long the hold is when it greets
them.

Off by default, and the single most effective setting against drive-by image
spam. Ten minutes (`600`) is a reasonable starting point.

## Blocked accounts

Accounts on the shared abuse lists the bot checks — plus its own list — are
removed when they **join by themselves**. An account *added* by an existing
member is not, on the assumption that a member vouching for someone is a
decision the bot should not overrule.

If a list cannot be reached, the join is allowed. A screening service being
down is not a reason to lock a group's door.

## What the bot will not do

- **It does not moderate admins.** An admin flooding stickers is a matter for
  the group's humans.
- **It does not read what it is not addressed with**, unless privacy mode is
  turned off for the bot in BotFather. That is Telegram's rule, and it is why
  sticker counting and link rewriting need privacy mode off to work at all.
- **It does not act across groups.** Someone removed from one group arrives in
  the next with a clean slate. There is no shared reputation, by design.
- **It does not keep a transcript.** See [Privacy](/docs/using/privacy).

<Callout type="warn">
Without **delete** and **ban** rights, every one of these can detect a problem
and do nothing about it — which looks exactly like a broken bot. If moderation
seems inert, check the bot's admin rights first.
</Callout>
