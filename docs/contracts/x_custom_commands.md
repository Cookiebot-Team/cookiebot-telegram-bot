## The trigger list is data, so it is not in `COMMAND_ALIASES`

`parse_command` resolves aliases from a static table; these names are folder
names. `CustomCommandName` therefore extracts the head itself and matches it
against `legacy_assets.custom_command_names()`. Two consequences worth
recording:

1. **Head extraction follows `parse_command`, not v1.** v1 stripped every `/`
   anywhere in the word and exactly two of its own five bot usernames
   (`Miscellaneous.py:147`), so `/louie@SCTarinBot` did not resolve to a folder
   at all. Matching the parser the rest of the codebase uses is what makes
   `@`-addressed commands work for every skin; nothing a group could have
   depended on changes.
2. **The router is registered last.** A folder named after a real command must
   never shadow the real one. A unit test asserts no such collision exists in
   the shipped catalog — today there is none.

Because these do not parse into a `ParsedCommand`,
`TenantCommandGateMiddleware` does not see them and
`tenants.disabled_commands` does not apply. The pack gate below is the
per-tenant control for this family.

## Handler packs — `tenants.handler_pack` finally has a reader

`cb_gateway/packs.py` maps a pack name to the set of **families** it provides;
this feature is family `legacy_custom`, and `PackProvides(LEGACY_CUSTOM)` on
the router is what reads `tenant.handler_pack` per update. `"core"` provides
it (v1 parity — the Cookiebot brand has always answered these), `"minimal"`
does not, and an unknown pack name falls back to `"core"` rather than silently
deleting commands. See that module for why this is one dispatcher with a
filter rather than the per-pack dispatchers `multi-tenant.mdx` first sketched.

**What v1 did when fun was off.** The dispatch `elif` is
`funfunctions and <name> in custom_commands` (`COOKIEBOT.py:281`), so with fun
off the chain falls through to the image-search branch on the next line: v1
answered `/louie` with a Google image search for "louie". This port replies
`fun_off` like every other fun command. The fall-through belongs to
`x_image_search`'s own port, which is where v1's catch-all is reproduced; it is
recorded here because the two features share the same `elif` chain.

## QA

a brand on the `minimal` pack.
